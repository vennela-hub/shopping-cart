# 🛒 Shopping Cart Web Application

A simple and interactive Shopping Cart web application developed using **HTML, CSS, and JavaScript**.

## ✨ Features

* Add products to the cart
* Increase and decrease product quantity
* Remove products from the cart
* Clear the entire cart
* Automatically calculate the total price
* Responsive and user-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📚 Concepts Used

* JavaScript Arrays
* JavaScript Objects
* Functions
* DOM Manipulation
* Event Handling
* Array Methods

## 🚀 How to Run

1. Download or clone this repository.
2. Open `shopping-cart.html` in a web browser.
3. Add products to the cart and interact with the application.
